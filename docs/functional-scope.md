# 功能范围

本文区分 Kiseki 的长期方向和当前要快速做出的个人原型。第一版只实现最短使用闭环。

## 长期功能方向

### 每日记录

- 输入自由文本形式的感想、事件和观察。
- 记录日期、标签和可选上下文。
- 查看和编辑过去的记录。

### AI 分析

- 提取事实、情绪、收获和成本。
- 输出整体体验分和基础属性向量。
- 给出简短摘要、评分依据和置信度。
- 允许用户根据自身感受调整评分方式。

### 长期路线

- 创建职业或生活路线。
- 为不同路线设置关注维度和特殊因素。
- 观察路线的每日变化与长期曲线。
- 比较不同选择的收益、成本和机会窗口。

### 复盘

- 查看周、月和长期趋势。
- 发现持续增长或持续消耗的模式。
- 根据真实使用逐步调整评分规则。

### 数据

- 默认保存在本地。
- 后续支持导出和备份。
- 明确外部模型会接触哪些文本。

## 当前最简原型

第一版只完成：

1. 在终端输入日期和当天感想。
2. 将原文写入 SQLite 的 `daily_records`。
3. 调用一个已经选定的模型 API。
4. 获取整体分、六维向量、摘要、依据和置信度。
5. 使用 Pydantic 把 JSON 解析为固定结构。
6. 将结果更新到同一条记录并在终端展示。
7. 可以列出历史记录并查看某条详情。

## 第一版不做

- 图形界面和账号系统。
- 多设备同步。
- 多模型 Provider 抽象。
- 分析历史、版本迁移和自动重算。
- 自动重试、任务队列和复杂错误状态。
- 完整单元测试套件和覆盖率要求。
- 路线计算引擎。
- 本地大模型部署。

## 完成判断

第一版达到以下状态即可开始真实使用：

- 能输入一段日记并看到模型评分。
- 关闭程序后，记录仍可从 SQLite 读取。
- `list` 和 `show` 可以查看已有内容。
- API Key 没有被写进源码或数据库。
- 人工试用几条记录后，输出大体符合个人直觉。

除此之外的问题先记录，不在第一版集中补齐。
